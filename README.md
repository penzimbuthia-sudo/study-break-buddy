# Study Break Buddy

A simple study-break application that helps users take short breaks by displaying motivational quotes.

## Live Demo

[View the live application](https://study-break-buddy-ten.vercel.app/)

## Features

* **Fetch a quote**

  * Retrieves a quote from the DummyJSON API

* **Take a break**

  * Click the break button to fetch and display a new quote

* **Save quotes**

  * Save quotes that you want to come back to later

## Technologies Used

* HTML
* CSS
* JavaScript
* DummyJSON API

## Running Locally

Clone the repository:

```bash
git clone https://github.com/penzimbuthia-sudo/study-break-buddy.git
```

Navigate into the project:

```bash
cd study-break-buddy
```

Open the application in your browser or run it using a local development server.
